# 产品目标与研发阶段

## 目标

室内视觉跟随无人机，以选定人员为目标。软件链路为相机、检测、跟踪、目标状态估计、跟随策略、轨迹规划、SafetyFSM 与 PX4 接口。飞行控制和执行器安全仍由 PX4 及人工权限约束。

## 阶段路线图

| 阶段 | 交付目标 | 主要验收证据 | 门禁 |
|---|---|---|---|
| M0-A | 开发自动化基础 | 已冻结的基础设施与控制面记录 | 已关闭 |
| Phase A | 稳定单人跟随的软件链路 | 单元、集成、录制回放、受控 SITL、RK3576 软件 RC | 按任务契约和人工权限推进 |
| Phase B | 具备可信深度/地图输入的避障跟随 | 碰撞与重规划回放、SITL 证据 | 另行批准 |
| Phase C | 多机与多视角研究 | 独立研究报告 | 独立立项 |
| HIL / 真实飞行 | 台架和边界内飞行验证 | 分阶段硬件、HIL 和飞行证据 | 明确 Human Authority |

Phase A 先完成坐标、时间戳、有效期、目标身份保持和安全状态机的契约，再逐层实现检测、跟踪、估计、跟随、约束规划与故障处理。每一阶段先形成测试与证据，再进入下一门禁；关键指标为 `UNKNOWN` 时不得宣称通过。
