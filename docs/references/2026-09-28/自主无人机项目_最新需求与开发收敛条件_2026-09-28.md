## 2. 项目目标与范围

### 2.1 用户已确认的核心目标

构建一套以 RK3588 为机载计算平台的自主无人机人体跟随与运动采集系统。在室内指定一个人后，飞机能够保持目标身份，在约三米距离平滑跟随；遇到障碍物时自主判断可通行路径并避让；根据人体骨架可见性主动改善观察位置；目标丢失或出现危险时按明确逻辑处置；必要时自主判断下方是否适合降落，并在条件满足时完成降落。

系统同时采集带真实尺度的三维人体骨架。本阶段以跟随稳定性、系统闭环能力及可用数据采集为重点，不以关节位置精度作为验收门槛。

### 2.2 阶段划分

1. **当前阶段**：使用现有七寸无人机，在划定安全区域的室内试验场地完成受控整机验证。
2. **后续平台阶段**：七寸平台通过后，再考虑缩小到三点五寸平台；迁移后需要重新验证，不能直接继承七寸平台的性能结论。
3. **后续环境阶段**：扩展为室内、室外通用型。

当前七寸阶段已包含自主避障、主动观察及自主降落区域判断，不应将这些能力全部推迟到最终产品阶段。空旷场地跟随可以作为中间验证步骤，但不等于本阶段最终通过。

### 2.3 本阶段不作出的承诺

- 不要求在任何遮挡条件下都获得完整、真实的骨架数据。
- 不承诺任意室内环境、任意障碍物或任意人员密度下均可运行。
- 玻璃门、密集人群、突然闯入等复杂场景需单独验收，不能由普通桌椅场景通过推定。
- 暂不优化或验收关节位置精度；但仍须区分观测、预测、补全和缺测。
- 不将约三米拍摄距离解释为所有绕障、暂停和异常状态下都必须严格保持的数值约束。

## 5. 工程建议与派生要求

本节用于落实上述目标，不表示用户已经指定算法、接口或数值参数。

### 5.1 职责划分

- **视觉感知**：输出目标身份、人体框、关键点、相对位置、采集时间和观测质量。
- **目标状态估计**：融合连续观测及飞机自身运动信息，估计目标相对状态和不确定性。
- **环境感知**：输出已观测障碍、可通行空间和未知区域；独立于人体检测。
- **局部跟随与观察规划**：联合距离、目标可见性、人体间距、障碍和运动约束选择参考轨迹。
- **飞控接口**：校验坐标、时间、有效期、指令限制及当前模式，向飞控传递受约束的参考。
- **飞控**：承担飞机自身状态估计及稳定控制。
- **数据记录**：保存可回放、可重新计算的数据，不阻塞控制链路。

姿态补偿只解决旋转影响，不能单凭姿态区分飞机平移与人体平移。需要核对可用的飞控速度、位置及其有效性。

### 5.2 平滑与实时性

- 先剔除身份切换、异常距离和关键点跳变，再进行状态估计。
- 状态滤波与指令平滑分别设计；滤波不是解决闭环震荡的唯一措施。
- 核查采集到指令的整体延迟及波动，防止过强滤波、帧积压造成滞后。
- 对参考点切换、目标重捕获和观察位置切换设置平滑转换，避免位置突跳。
- 控制链路优先使用及时有效的观测；记录链路的负载和故障不能拖慢跟随。

### 5.3 主动观察

- 观察改善应在安全可达空间内进行；不能为了看全腿部而穿过未知或不通行区域。
- 对视角收益、切换确认和搜索范围建立规则，避免持续左右试探。
- 完整骨架是优先目标，受限环境下允许按 REQ-07 退化。
- 前向相机不能自动证明侧后方可通行；传感器覆盖与可允许运动方向需一致。

### 5.4 降落判断

- 区分“高度已知”“下方可观测”“区域适合降落”和“下降过程中持续安全”。
- 下视测高雷达的存在，不构成降落区域安全识别的完成证据。
- 对不安全或无法判断的区域，不应仅因等待超时就无条件下降。
- 必须补齐无安全降落位置、定位退化、电量不足等情况下的处置逻辑，不能无限等待，也不能假设任何故障下都能悬停。
- 当前确认的是判断下方区域是否适合降落；自主搜索远处降落点、返航及跨区域备降不应被默认为已纳入本阶段范围。

### 5.5 数据记录

建议至少保留：左右原始图像或视频及逐帧时间戳、相机标定与安装外参、左右二维关键点和置信度、目标身份、初步三维骨架、飞控状态及对应时间、跟随与失效状态日志。

每个数据结果应区分真实观测、短时预测、模型补全和缺测。三维输出应声明单位、坐标系及尺度来源。只保存最终骨架会限制后续项目重新处理的能力。

需区分相机坐标下有尺度的局部骨架与长期稳定的场地坐标轨迹；后者受飞机自身定位漂移影响，不能默认已经实现。

## 6. 七寸平台的综合验收场景

用户认可的验收形式是：在划定安全区域的室内试验场地，重复完成“指定人员—稳定跟随—避障—异常处置—降落”的完整演示，并提供录像和飞行记录。

| 环节 | 场景与期望 |
|---|---|
| 指定人员 | 明确选定一个人，后续保持该身份 |
| 日常动作 | 人正常走动、转弯、停下、坐下、起身；飞机平滑跟随，保持约三米 |
| 他人干扰 | 旁人走动或交叉经过，不随意切换跟踪对象 |
| 障碍绕行 | 桌椅或隔断阻挡直接路径，有安全通道时自主绕行 |
| 观察改善 | 人体局部被挡且有安全的更好视角时，主动调整观察位置 |
| 不可改善遮挡 | 无安全的更好视角时悬停；头、肩、躯干可见，允许继续采集部分骨架 |
| 暂时丢失 | 允许暂停；原目标重新出现、身份确认后恢复 |
| 身份模糊 | 保持安全等待，不擅自跟随其他人 |
| 持续丢失 | 按预定规则等待，并自主判断下方降落条件；满足条件时自动降落 |
| 证据与重复性 | 录像、遥测、感知和状态日志能够对应；需重复成功 |

安全员具备接管能力是试验前提，不能作为自主能力缺失的替代。正常跟随、绕障、观察调整和降落不能依赖反复人工纠正。

## 9. 推荐推进顺序

以下是工程推进建议，不改变用户已确认的最终验收要求。

1. **建立需求—实现—证据对照表**：逐条检查 REQ-01 至 REQ-14，定位代码与测试，避免凭历史总结判断完成。
2. **闭合接口和感知覆盖**：核对时钟、坐标、单位、数据时效，明确前向、侧向及下方观测能力。
3. **验证真实输入的数据链**：机载采集、身份、距离、飞控状态与骨架记录；控制输出边界按当前授权保持。
4. **验证跟随与失效逻辑**：先回放和仿真，检查平滑、停走、重捕获及过期数据。
5. **验证避障与主动观察**：分别覆盖可通行、不可通行、未知空间和不可改善遮挡。
6. **验证降落判断与异常链**：覆盖适合、不适合及无法判断的区域，并闭合无法降落时的行为。
7. **按项目批准的试验流程完成综合验证**：通过受控条件下的重复演示与证据审查，才宣布七寸阶段通过。
