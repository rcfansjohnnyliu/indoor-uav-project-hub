# HGAF 具体研发方案

> 历史方案摘要。2026-09-28 补充需求的当前开发顺序、任务覆盖和完成门禁见[最新计划](../tasks/plan.md)。下方旧阶段划分及 M6-T03 绑定说明不作当前运行态依据。

此页整理 Control Plane `docs/architecture/hgaf-replan/03_HGAF_DEVELOPMENT_PLAN.md` 的 G0–G13 方案。原文标记为 `PROPOSAL — NOT EXECUTION AUTHORITY`；此页是研发管理视图，不替代逐任务契约或人工授权。

| 门禁 | 开发交付 | 通过所需证据 | 阻断条件 |
|---|---|---|---|
| G0 | 人工确认架构重规划 | 架构决策和授权任务契约 | 未批准前不得开发 |
| G1 | 版本化输入、状态与输出契约 | schema、单元测试、坐标与新鲜度决策 | 坐标系或单位含糊 |

| G3 | 跟踪与目标身份 | 多人、交叉、遮挡基准报告 | 身份切换超限 |
| G4 | 目标状态估计 | 预测与不确定性回放测试 | 状态过期或无界 |
| G5 | 跟随策略和动态目标 | 确定性参考轨迹 | 原始检测框直达控制 |
| G6 | 运动约束层 | 速度、加速度、jerk、偏航性质测试 | 约束越界或不连续 |
| G7 | EGO 思路的 Phase A 原型 | 独立实现测试、性能数据、许可审查 | 许可不明或超时 |
| G8 | SafetyFSM | 优先级、超时、人工接管转换矩阵 | 人工接管无法抢占 |
| G9 | 闭环 SITL | SCENE-01 至 13 的机器可读证据 | 缺少 SITL 授权或安全失败 |
| G10 | RK3576 软件候选版 | ARM64/RKNN 加载、时延、FPS、内存、温度 | 关键指标未知或超预算 |
| G11 | Phase B 深度与地图 | 回放和 SITL 碰撞证据 | 缺少可信深度或地图 |
| G12 | HIL、真实飞行 | 分阶段硬件与飞行证据 | 缺少明确人工/硬件授权 |
| G13 | 多机研究 | 独立研究报告 | Phase A/B 未稳定或未立项 |

## 每阶段工作包

每个门禁按同一流程交付：确认前置条件与任务权限；冻结输入版本和预期 HEAD；实现最小软件切片；执行单元、集成和录制回放验证；记录不可变证据；审查失败与未知项；由对应验收机制决定是否进入下一阶段。涉及 SITL、硬件、HIL 或飞行时先检查专属 Human Authority。

## 当前最近任务：M6-T03

目标是离线、非 arming 的命令路径验证，限定于 Product 仓库的 `src/**`、`tests/**` 和 `tasks/product/**`。计划使用确定性 mock/录制输入，验证 arming/执行器输出拒绝路径及输出授权保持关闭，并运行 `make verify` 和 `make safety-check`。当前检查点仍待任务专属授权、Dashi 绑定刷新、不可变修订发布及派发前检查；此计划本身不授权执行。

## 验收数据

各模块需逐级留下单元、集成、录制回放、受控 SITL、RK3576 软件候选版、HIL 和真实飞行的相应证据。目标身份切换、恢复时间、时延、FPS、控制约束、CPU/RAM/温度与人工接管响应的数值门槛须以测量或批准的契约确定；未知关键门槛阻断晋级。详见原 Control Plane `docs/architecture/hgaf-replan/07_HGAF_ACCEPTANCE_MATRIX.md`。
