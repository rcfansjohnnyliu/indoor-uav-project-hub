## 对开发路线的修正

1. PX4 继续承担自身状态估计和稳定控制；机载软件生成经校验的高层位置/速度/偏航参考，具体接口选择按实际 1.15.4 与连接方式核实。
2. 当前优先链路为：前视采集 → 人体/躯干与指定身份 → 相对位置及有效性 → 平滑跟随参考 → 飞控接口 → PX4 执行反馈。实际飞控连接和输出各自沿任务权限处理。
3. 先把“观察人体后产生正确指令”“飞控正确接收并解释指令”“飞行响应与视觉闭环稳定”逐级验证；自主避障、主动观察、降落判断和米制骨架仍属于已约定范围。
4. 已稳定的定位飞行作为用户确认的前置能力复用；归档可用参数/日志并检查新增链路，不重做整套基础飞控研发，也不将定位模式稳定直接等同于 Offboard 跟随稳定。
5. 原开源参考中 PX4 1.16 文档只是历史研究来源，实施必须核对 **1.15.4** 的接口、模式及失效行为；本轮不建议为匹配示例而升级固件。

## 仍需明确的集成接口

用户补充确认：**RK3588 和前视相机尚未安装，当前不能出图；机载电脑与飞控采用 USB 连接。** USB 为确定的连接方案，尚无已连通证据。具体相机、供电、安装位置及 USB 设备识别/协议配置仍需落实。

首阶段并行推进：用录制视频开发人体识别与跟踪；落实机载安装、供电和相机出图；在获准的接口验证任务中检查 USB 枚举、遥测与连接恢复。相机出图与 USB 通信验证是实机闭环前置条件，应纳入首个双周里程碑；未完成时只能报告视频软件演示，不能标记机载集成通过。

MTF-01P 的下视测距用于已有定位链路，不能直接替代相机到人体的约三米相对距离，也不能证明前向避障或下方降落区域判断。同步双目优先候选及下方区域感知的剩余缺口继续按[需求对照](06-requirements-gap-2026-09-28.md)管理。
